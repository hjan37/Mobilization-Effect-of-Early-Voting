# Codebook: `early_voters_n319.csv`

제22대 국회의원선거 외부평가 조사(2024.05.23) 원자료에서 **사전투표자 319명**을 추출하고,
분석에 필요한 변수를 리코딩한 데이터셋이다.

## 종속변수

| 변수명 | 설명 | 값 |
|--------|------|----|
| `mobilized` | 동원 여부 (가설적 문항 기반) | 1 = 동원 (사전투표제 없었으면 투표 불가), 0 = 대체 (투표 가능) |
| `counterfactual` | 원 응답 (Q4A: 사전투표제 부재시 투표 가능성) | 1 = 투표할 수 있었다, 2 = 투표할 수 없었다 |

## 독립변수 (개인수준)

| 변수명 | 설명 | 값 |
|--------|------|----|
| `female` | 여성 더미 | 1 = 여성, 0 = 남성 |
| `age` | 연령 (만) | 19–81 |
| `age10` | 연령/10 | 1.9–8.1 |
| `pol_interest` | 정치관심도 (Q2) | 1 = 매우 관심 … 4 = 전혀 무관심 |
| `elec_interest` | 선거관심도 (Q1) | 1 = 매우 관심 … 4 = 전혀 무관심 |
| `education` | 학력 (DQ1) | 1 = 초졸 이하, 2 = 중졸, 3 = 고졸, 4 = 전문대, 5 = 4년제, 6 = 석사, 7 = 박사 이상 |
| `income` | 가구소득 (DQ7) | 1 = 100만 미만 … 11 = 1,000만 이상 |
| `ideology` | 주관적 이념 성향 (Q22) | 0 (매우 진보) – 10 (매우 보수) |

## 정당일체감 변수

| 변수명 | 설명 | 비고 |
|--------|------|------|
| `party_ident_q19` | 정당일체감 유무 (**모형 1**) | Q19("친밀하게 느끼는 정당 유무") 단독 기준. 1 = 있다 (n=205), 0 = 없다 (n=114) |
| `pid_dem` | 민주당 일체감 더미 (**모형 2**) | Q19B 기준. 1 = 더불어민주당 |
| `pid_ppp` | 국민의힘 일체감 더미 (**모형 2**) | Q19B 기준. 1 = 국민의힘 |
| `pid_other` | 기타정당 일체감 더미 (**모형 2**) | Q19B 기준. 1 = 새로운미래·개혁신당·녹색정의당·조국혁신당·기타 |
| `party_q19` | 원 응답: 친밀 정당 유무 (Q19) | 1 = 있다, 2 = 없다 |
| `party_q19a` | 원 응답: 조금이라도 더 친밀한 정당 유무 (Q19A) | 1 = 있다, 2 = 없다. Q19=2인 경우만 응답 |
| `party_which` | 원 응답: 친밀 정당 (Q19B) | 1 = 민주당, 2 = 국힘, 4 = 개혁신당, 5 = 녹색정의당, 6 = 조국혁신당 |

### 모형 1과 모형 2의 비내포(non-nested) 구조

- **모형 1**: `party_ident_q19` = Q19 응답 기준 → 205명이 "정당일체감 있음"
- **모형 2**: `pid_dem`/`pid_ppp`/`pid_other` = Q19B 응답 기준 → Q19 **또는** Q19A에 "있다"고 응답한 247명
- Q19="없다"이지만 Q19A="있다"인 **42명**이 모형 1에서는 무당파(0), 모형 2에서는 특정 정당(1)으로 코딩됨
- 따라서 두 모형은 엄밀한 내포관계(nested model)가 아님
