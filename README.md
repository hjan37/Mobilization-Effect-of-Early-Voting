# 사전투표제도의 투표율 제고 효과 — 표 8 재현 패키지

> 제22대 국회의원선거에 대한 가설적 설문 문항과 위계적 일반화 선형모형(GLMM)을 활용한 실증 분석

> **저널**: 한국정치연구 

> 수정 후 게재시 재현을 위해 공개

## 개요

본 저장소는 논문의 **표 8(사전투표자의 동원 결정요인 추정)** 결과를 완전히 재현하기 위한 데이터와 R 코드를 포함합니다.

### 분석 모형

* **종속변수**: 동원 여부 (1 = 동원, 0 = 대체)

  * 가설적 문항(Q4A): "사전투표제도가 없었다면 선거일에 투표할 수 있었습니까?"
  * "투표할 수 없었다" → 동원(1), "투표할 수 있었다" → 대체(0)
* **분석 단위**: 사전투표자 319명 (전체 응답자 1,000명 중)
* **모형**: 이항 로지스틱 일반화 선형 혼합모형 (Binomial GLMM, Laplace 근사)

  * Level-1: 개인수준 변수 (성별, 연령, 정치관심도, 선거관심도, 교육, 소득, 이념, 정당일체감)
  * Level-2: 17개 시·도 (랜덤 절편)

|모형|정당일체감 변수|Log-Likelihood|AIC|BIC|
|-|-|-|-|-|
|모형 1|정당일체감 유무 (이분변수)|−200.9|421.8|459.5|
|모형 2|정당별 일체감 (민주당·국민의힘·기타정당 더미)|−201.5|427.0|472.2|

### 

### 비내포(Non-nested) 구조에 대한 주석

모형 1의 정당일체감 유무는 Q19("친밀하게 느끼는 정당이 있는가") 단독 기준(205명)이고,
모형 2의 정당별 더미는 Q19B(Q19 **또는** Q19A 응답자, 247명) 기준입니다.
Q19="없다"이지만 Q19A="있다"인 42명이 두 모형에서 다르게 코딩되므로,
두 모형은 엄밀한 내포관계가 아닙니다.
따라서 LL(모형 1) > LL(모형 2)는 통계적으로 문제없으며, AIC/BIC 비교가 적절합니다.
